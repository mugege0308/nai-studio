# Japanese tag dictionary attribution

The generated dictionary is sourced from the public tags.json published by
[PYU224/tagdb-updater](https://github.com/PYU224/tagdb-updater).

- Repository license: MIT, as published in
  [LICENSE.txt](https://github.com/PYU224/tagdb-updater/blob/main/LICENSE.txt).
- Upstream data provenance: the upstream README says tag metadata and wiki
  aliases are obtained from Danbooru public API/wiki data. The upstream
  project describes itself as unofficial and does not grant a blanket
  copyright or redistribution license for every upstream-derived record.
- Japanese translations can come from upstream wiki names and translation CSVs;
  upstream warns that some translations are machine-generated.

NAI Studio keeps this attribution with the generated shards. This app does not
redistribute Danbooru images. Users should independently review any
jurisdiction-specific terms before public redistribution of derived data.

The maintained synonym map in synonyms.json is NAI Studio data and is not
replaced by the weekly updater.
